# solvers-web

Sitio web corporativo de **Solvers Industriales, C.A.** — [solversindustriales.com](https://solversindustriales.com)

Sitio estático en [Astro](https://astro.build), en español e inglés, publicado en GitHub Pages con GitHub Actions.

## Desarrollo

Requiere Node.js ≥ 22.22 (recomendado 24 LTS).

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # genera dist/
npm run preview   # sirve dist/
```
